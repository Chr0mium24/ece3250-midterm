2.4 带端点质量的摆：状态空间、线性化、传递函数Pendulum with a tip mass: state space, linearization, transfer function

均匀杆（长 $L$、质量 $m$）下端挂点质量 $M$，上端铰接；输入力矩 $\tau(t)$，输出角度 $\theta$（从竖直向下量起），无摩擦。运动方程：

A uniform rod (length $L$, mass $m$) with a point mass $M$ at its lower end, pivoted at the top; input torque $\tau(t)$, output angle $\theta$ measured from the downward vertical, no friction:

$$(M+\tfrac m3)L^2\,\ddot\theta=\tau-(M+\tfrac m2)Lg\sin\theta$$

(a) 取 $x_1=\theta,\ x_2=\dot\theta,\ u=\tau$，写状态空间模型，$y=\theta$。(b) 是否线性？在 $\theta=\dot\theta=\tau=0$ 处线性化。(c) 求线性化系统的 $G(s)=\Theta(s)/T(s)$。

(a) With $x_1=\theta,\ x_2=\dot\theta,\ u=\tau$, write a state-space model with $y=\theta$. (b) Is it linear? Linearize about $\theta=\dot\theta=\tau=0$. (c) Find $G(s)=\Theta(s)/T(s)$ of the linearized system.

解答Solution

(a)

$$\dot x_1=x_2,\qquad \dot x_2=\frac{u-(M+\frac m2)Lg\sin x_1}{(M+\frac m3)L^2},\qquad y=x_1$$

(b) 因为有 $\sin x_1$，所以不是线性系统。检查工作点：$f(0,0)=\big[0,\ 0\big]^T$，$(x_0,u_0)=(0,0)$ 是平衡点。求 Jacobian：Because of $\sin x_1$ the system is nonlinear. Check the operating point: $f(0,0)=[0,\ 0]^T$, so $(x_0,u_0)=(0,0)$ is an equilibrium. Jacobians:

$$\frac{\partial f_2}{\partial x_1}=-\frac{(M+\frac m2)g\cos x_1}{(M+\frac m3)L}\Big|_0=-\frac{(M+\frac m2)g}{(M+\frac m3)L},\qquad \frac{\partial f_2}{\partial x_2}=0,\qquad \frac{\partial f_2}{\partial u}=\frac{1}{(M+\frac m3)L^2}$$ $$\dot{\tilde x}=\underbrace{\begin{bmatrix}0&1\\-\omega_0^2&0\end{bmatrix}}_{A}\tilde x+\underbrace{\begin{bmatrix}0\\ \frac{1}{(M+\frac m3)L^2}\end{bmatrix}}_{b}\tilde u,\qquad \tilde y=\underbrace{[1\ \ 0]}_{c}\tilde x,\ d=0,\qquad \omega_0^2=\frac{(M+\frac m2)g}{(M+\frac m3)L}=\frac{3(2M+m)g}{2(3M+m)L}$$

(c)

$$G(s)=c(sI-A)^{-1}b=\frac{1/[(M+\frac m3)L^2]}{s^2+\omega_0^2}=\frac{1}{(M+\frac m3)L^2s^2+(M+\frac m2)gL}$$

自检：$m=0$ 时退化成点质量摆 $\frac{1}{ML^2s^2+MgL}$；极点 $\pm j\omega_0$ 在虚轴上（无摩擦，临界，不是 BIBO 稳定）。

Sanity check: $m=0$ gives the point-mass pendulum $\frac{1}{ML^2s^2+MgL}$; poles $\pm j\omega_0$ lie on the imaginary axis (frictionless, not BIBO stable).

2.9 比例输出反馈后的闭环状态空间Closed-loop state space under proportional output feedback

对象 $\dot x=Ax+bu,\ y=cx$，接负比例输出反馈 $u(t)=r(t)-Ky(t)$。求以 $r$ 为输入、$y$ 为输出的闭环状态空间模型。

The plant $\dot x=Ax+bu,\ y=cx$ is connected in negative proportional output feedback $u(t)=r(t)-Ky(t)$. Obtain the closed-loop state-space model from $r$ to $y$.

解答Solution

把 $u=r-Kcx$ 代入状态方程：

Substitute $u=r-Kcx$ into the state equation:

$$\dot x=Ax+b(r-Kcx)=(A-Kbc)\,x+b\,r,\qquad y=cx$$

即闭环矩阵 $(A_{cl},b_{cl},c_{cl},d_{cl})=(A-Kbc,\ b,\ c,\ 0)$。传递函数验证：$c(sI-A+Kbc)^{-1}b=\dfrac{G}{1+KG}$，其中 $G=c(sI-A)^{-1}b$，和方框图公式一致。

So $(A_{cl},b_{cl},c_{cl},d_{cl})=(A-Kbc,\ b,\ c,\ 0)$. Check with transfer functions: $c(sI-A+Kbc)^{-1}b=\dfrac{G}{1+KG}$ with $G=c(sI-A)^{-1}b$, matching the block-diagram formula.

变形Variant若 $y=cx+du$ 且 $d\ne0$：$u=\frac{r-Kcx}{1+Kd}$ ⟹ $A_{cl}=A-\frac{K}{1+Kd}bc$，$b_{cl}=\frac{b}{1+Kd}$，$c_{cl}=\frac{c}{1+Kd}$，$d_{cl}=\frac{d}{1+Kd}$（需要 $1+Kd\ne0$，即适定）。If $y=cx+du$ with $d\ne0$: $u=\frac{r-Kcx}{1+Kd}$ ⟹ $A_{cl}=A-\frac{K}{1+Kd}bc$, $b_{cl}=\frac{b}{1+Kd}$, $c_{cl}=\frac{c}{1+Kd}$, $d_{cl}=\frac{d}{1+Kd}$ (requires $1+Kd\ne0$, i.e. well-posedness).

2.10 方框图化简Block-diagram reduction

解答Solution

代数消元：设 $A$ 的输出（引出点）为 $v$。

Algebraic elimination: let $v$ be the output of $A$ (the pickoff point).

$$v=A\,(r-EBv)\ \Rightarrow\ v=\frac{A}{1+ABE}\,r,\qquad y=BCv+Dv=(BC+D)\,v$$ $$\boxed{G(s)=\frac{Y}{R}=\frac{A(s)\big[B(s)C(s)+D(s)\big]}{1+A(s)B(s)E(s)}}$$

方框图化简：(1) 内环：前向 $A$，反馈 $EB$，负反馈 ⟹ $\frac{A}{1+AEB}$；(2) 引出点之后的两条支路 $BC$ 和 $D$ 并联 ⟹ $BC+D$；(3) 两者串联。

Diagram reduction: (1) inner loop, forward $A$, feedback $EB$, negative ⟹ $\frac{A}{1+AEB}$; (2) after the pickoff, branches $BC$ and $D$ are in parallel ⟹ $BC+D$; (3) cascade the two.

注意Watch out反馈通路是 $E(s)B(s)$，不是 $E(s)$；引出点在 $A$ 后、$B$ 前，所以 $D$ 支路不经过 $B$。The feedback path is $E(s)B(s)$, not $E(s)$; the pickoff is after $A$ and before $B$, so the $D$ branch bypasses $B$.

闭环特征多项式（$p=s^2$，$q=1$）：

Closed-loop characteristic polynomial ($p=s^2$, $q=1$):

$$c(s)=s^2(s^2+a_1s+a_2)+b_1s+b_2=s^4+a_1s^3+a_2s^2+b_1s+b_2$$

The coefficients vary independently, so this is an interval polynomial: $[1,1],[2,3],[4,6],[2,3],[1,2]$. The four Kharitonov polynomials (from $s^4$, LLUU / LUUL / ULLU / UULL):

3.22 $(K,\tau)$ 平面的稳定区域Stability region in the $(K,\tau)$ plane

$$L(s)=\frac{K(s+2)}{s(1+\tau s)(1+2s)}\qquad(\text{unity negative feedback})$$

求并画出 $(K,\tau)$ 平面上的稳定区域。

Determine and plot the region of stability in the $(K,\tau)$ plane.

解答Solution

特征多项式：$s(1+\tau s)(1+2s)+K(s+2)=0$，展开 $s(1+\tau s)(1+2s)=2\tau s^3+(\tau+2)s^2+s$：

Characteristic polynomial: $s(1+\tau s)(1+2s)+K(s+2)=0$ with $s(1+\tau s)(1+2s)=2\tau s^3+(\tau+2)s^2+s$:

$$c(s)=2\tau s^3+(\tau+2)s^2+(1+K)s+2K$$
$s^3$$2\tau$$1+K$
$s^2$$\tau+2$$2K$
$s^1$$\dfrac{(\tau+2)(1+K)-4\tau K}{\tau+2}$
$s^0$$2K$

（$\tau$ 是时间常数，取 $\tau>0$；可以验证 $\tau\lt 0$ 时第一列不可能同号。）条件：

($\tau$ is a time constant, so $\tau>0$; one can check that for $\tau\lt 0$ the first column can never have a single sign.) Conditions:

$$\tau>0,\qquad K>0,\qquad (\tau+2)(1+K)-4\tau K>0\iff \tau(1-3K)+2(1+K)>0$$
  • $0\lt K\le\frac13$：对所有 $\tau>0$ 都稳定。
  • $0\lt K\le\frac13$: stable for every $\tau>0$.
  • $K>\frac13$：$\tau\lt \dfrac{2(1+K)}{3K-1}$。边界曲线过 $(1,2)$、$(2,1.2)$、$(3,1)$，$K\to\frac13^+$ 时 $\tau\to\infty$，$K\to\infty$ 时 $\tau\to\frac23$。
  • $K>\frac13$: $\tau\lt \dfrac{2(1+K)}{3K-1}$. The boundary passes through $(1,2)$, $(2,1.2)$, $(3,1)$, with $\tau\to\infty$ as $K\to\frac13^+$ and $\tau\to\frac23$ as $K\to\infty$.
  • 等价写法：$\tau\le\frac23$ 时只需 $K>0$；$\tau>\frac23$ 时 $0\lt K\lt \dfrac{\tau+2}{3\tau-2}$。
  • Equivalently: for $\tau\le\frac23$ only $K>0$ is needed; for $\tau>\frac23$, $0\lt K\lt \dfrac{\tau+2}{3\tau-2}$.

绿色 = 稳定（逐点用 Routh 判定）；红色虚线 = 解析边界 $\tau=\frac{2(1+K)}{3K-1}$。鼠标移到图上看坐标。Green = stable (Routh test at each grid point); red dashed = analytic boundary $\tau=\frac{2(1+K)}{3K-1}$. Hover to read coordinates.
