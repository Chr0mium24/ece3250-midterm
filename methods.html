题目处理：按题型拆解Problem types: how to attack each one 每类题：看到什么信号 → 按什么步骤 → 答案写成什么样 → 哪里会丢分。最后附一个对应的计算器。For each type: what to look for → the steps → what the answer should look like → where marks are lost, plus the matching calculator.

考场通用Exam habits ① 多项式统一写成降幂 $a_0s^n+\dots+a_n$，先把首项化正；② Routh、极点配置一律用分数算，不要用小数；③ 求出参数范围后代入一个内点、一个外点检查；④ 稳定性结论写完整：“稳定 / 不稳定 + 依据（Routh 第一列 / 极点位置 / 定理）”。 ① Always write polynomials in descending powers $a_0s^n+\dots+a_n$ with $a_0>0$; ② keep Routh and pole-placement arithmetic in fractions, not decimals; ③ after finding a parameter range, test one point inside and one outside; ④ state stability conclusions fully: “stable / unstable + reason (Routh first column / pole locations / theorem)”.

1 · 物理系统 → 状态空间Physical system → state space

识别Signals：给电路图 / 小车弹簧阻尼 / 电机，问 “write a state-space model”。A circuit, carts with springs/dampers, or a motor, and “write a state-space model”.

  1. 定输入、输出，选状态：每个电容电压、每个电感电流；每个质量的位置和速度；电机取 $i_a$ 和 $\omega$（要位置再加 $\theta$）。Fix input and output, pick states: every capacitor voltage, every inductor current; position and velocity of every mass; for a motor $i_a$ and $\omega$ (add $\theta$ if position is needed).
  2. 写物理定律：电容所在节点用 KCL（$C\dot v=\sum i$），电感所在回路用 KVL（$L\dot i=\sum v$），质量用 $M\ddot x=\sum F$，转动用 $J\ddot\theta=\sum\tau$。Write the laws: KCL at capacitor nodes ($C\dot v=\sum i$), KVL around inductor loops ($L\dot i=\sum v$), $M\ddot x=\sum F$ for masses, $J\ddot\theta=\sum\tau$ for rotation.
  3. 每个方程解出一个导数，按状态顺序排成 $\dot x=Ax+bu$；输出写成 $y=cx+du$。Solve each equation for one derivative, stack them as $\dot x=Ax+bu$, and write $y=cx+du$.
  4. 高阶 ODE $x^{(n)}+a_1x^{(n-1)}+\dots+a_nx=u$：$x_1=x,\dots,x_n=x^{(n-1)}$，最后一行 $[-a_n\ \cdots\ -a_1]$。For $x^{(n)}+a_1x^{(n-1)}+\dots+a_nx=u$: $x_1=x,\dots,x_n=x^{(n-1)}$, last row $[-a_n\ \cdots\ -a_1]$.
坑Traps受控源 $gv_1$ 的方向（流出节点为负）；阻尼力是相对速度 $F(\dot x_1-\dot x_2)$；电机 KVL 里反电势 $K\dot\theta$ 的符号；$M$ 不能漏除。Direction of the controlled source $gv_1$ (leaving the node is negative); damper force uses relative velocity $F(\dot x_1-\dot x_2)$; sign of the back-emf $K\dot\theta$; don't forget to divide by $M$.

2 · 非线性 → 线性化Nonlinear → linearize

识别Signals：方程里有 $\sin\theta$、$i^2/y^2$、乘积项；“linearize about …”、“operating point”。$\sin\theta$, $i^2/y^2$ or product terms; “linearize about …”, “operating point”.

  1. 写成 $\dot x=f(x,u)$，$y=g(x,u)$（先像题型 1 那样选状态）。Write $\dot x=f(x,u)$, $y=g(x,u)$ (choose states as in type 1).
  2. 求工作点：令 $f(x_0,u_0)=0$，题目通常给出期望输出 $y_0$（MagLev）或直接给工作点（单摆 $\theta=0$）。把 $x_0$ 每个分量和 $u_0$ 都解出来。Operating point: solve $f(x_0,u_0)=0$; usually the desired output $y_0$ is given (MagLev) or the point itself (pendulum $\theta=0$). Solve for every component of $x_0$ and for $u_0$.
  3. 求 Jacobian：$A_{ij}=\partial f_i/\partial x_j$，$b_i=\partial f_i/\partial u$，$c_j=\partial g/\partial x_j$，$d=\partial g/\partial u$，先求导再代入工作点。Jacobians: $A_{ij}=\partial f_i/\partial x_j$, $b_i=\partial f_i/\partial u$, $c_j=\partial g/\partial x_j$, $d=\partial g/\partial u$ — differentiate first, then substitute.
  4. 答案写成 $\dot{\tilde x}=A\tilde x+b\tilde u,\ \tilde y=c\tilde x+d\tilde u$，并注明 $\tilde x=x-x_0$ 等。Answer: $\dot{\tilde x}=A\tilde x+b\tilde u,\ \tilde y=c\tilde x+d\tilde u$ with $\tilde x=x-x_0$ etc. stated.
常用导数Handy derivatives $\frac{\partial}{\partial\theta}\sin\theta=\cos\theta$；$\frac{\partial}{\partial x_1}\frac{x_1^2}{x_2^2}=\frac{2x_1}{x_2^2}$，$\frac{\partial}{\partial x_2}\frac{x_1^2}{x_2^2}=-\frac{2x_1^2}{x_2^3}$；$\frac{\partial}{\partial x_2}\frac{h(x)}{L(x_2)}\Big|_0=\frac{\partial h/\partial x_2}{L}-\frac{h\,L'}{L^2}$，若工作点处 $h=0$ 则第二项消失（MagLev 的 $A_{12}=0$）。; if $h=0$ at the operating point the second term vanishes (MagLev's $A_{12}=0$).
坑Traps忘了求 $u_0$；直接对线性化前的 $x$ 写答案（应为偏差变量）；把 $\cos\theta$ 代成 0 而不是 1（在 $\theta=0$ 处 $\cos=1$）；倒立摆在竖直向上平衡时 $\sin\theta\approx\theta$ 但重力项符号为正（不稳定）。Forgetting $u_0$; writing the result in $x$ instead of deviation variables; substituting $\cos 0=0$ instead of 1; for an upright pendulum the gravity term keeps a positive sign (unstable).

3 · 状态空间 → 传递函数（含闭环）State space → transfer function (incl. closed loop)

  1. 写 $sI-A$，算 $\det(sI-A)=a(s)$（分母）。Form $sI-A$ and compute $\det(sI-A)=a(s)$ (denominator).
  2. 只需要 $(sI-A)^{-1}$ 中被 $c$ 和 $b$ 选中的元素：$(sI-A)^{-1}_{ij}=\dfrac{(-1)^{i+j}M_{ji}}{\det(sI-A)}$（注意下标转置）。若 $c=e_k^T$、$b=\beta e_l$，则 $G=\beta\,(sI-A)^{-1}_{kl}$。Only the entries picked by $c$ and $b$ are needed: $(sI-A)^{-1}_{ij}=\dfrac{(-1)^{i+j}M_{ji}}{\det(sI-A)}$ (note the transposed minor). If $c=e_k^T$, $b=\beta e_l$, then $G=\beta\,(sI-A)^{-1}_{kl}$.
  3. $G=c(sI-A)^{-1}b+d$；化简后检查：分母阶数 = $n$（除非有对消），$d\ne0$ 时 bi-proper。$G=c(sI-A)^{-1}b+d$; check that the denominator has degree $n$ (unless something cancels) and that $d\ne0$ makes it bi-proper.
  4. 闭环 $u=r-Ky$：$A_{cl}=A-Kbc$，TF $=\frac{G}{1+KG}$。Closed loop $u=r-Ky$: $A_{cl}=A-Kbc$, TF $=\frac{G}{1+KG}$.
2×2 秒算2×2 shortcut$\begin{bmatrix}a&b\\c&d\end{bmatrix}^{-1}=\frac{1}{ad-bc}\begin{bmatrix}d&-b\\-c&a\end{bmatrix}$。例E.g. $A=\begin{bmatrix}0&1\\-1&-2\end{bmatrix},b=\begin{bmatrix}0\\1\end{bmatrix},c=[2\ 1]$ ⟹ $G=\frac{s+2}{s^2+2s+1}$.

4 · 方框图化简Block-diagram reduction

两条路，选更稳的那条Two routes — pick the safer one

  1. 代数消元（推荐，最不容易错）：给每个求和点输出、每个引出点起一个名字（$e,v,\dots$），每个求和点写一条方程（注意 “−” 号），消去中间变量。Algebraic elimination (recommended, hardest to get wrong): name the output of every summing junction and every pickoff ($e,v,\dots$), write one equation per junction (mind the “−”), eliminate the intermediates.
  2. 图形化简：先串并联；再消最内层的环 $\frac{G}{1\mp GH}$；环与环交叉时移动求和点 / 引出点（补 $G$ 或 $1/G$）把它们拆开；一路化到单个方块。Graphical reduction: combine series/parallel; close the innermost loops $\frac{G}{1\mp GH}$; if loops overlap, move summing/pickoff points (inserting $G$ or $1/G$) to separate them; repeat until one block remains.
  3. 多输入（如 $R$ 和 $D$）：叠加原理，每次只留一个输入，其余置 0。所有闭环传递函数的分母应该相同。Several inputs (e.g. $R$ and $D$): superposition — keep one input at a time. All closed-loop TFs must share the same denominator.
坑Traps没标 “−” 的求和输入是 “+”（课件复杂例的 Loop 1 是正反馈）；移动求和点“向前移补 $1/G$、向后移补 $G$”别弄反；引出点在方块后时，移到方块前要补 $G$。Unmarked summing inputs are “+” (Loop 1 in the slide example is positive feedback); moving a junction backwards inserts $1/G$, forwards inserts $G$ — don't swap; moving a pickoff from after a block to before it inserts $G$.

5 · 拉氏反变换、冲激/阶跃响应、DC gainInverse Laplace, impulse/step responses, DC gain

  1. 冲激响应 $g=\L^{-1}[G]$；阶跃响应 $y=\L^{-1}[G/s]$。若 $\deg$ 分子 $\ge$ 分母，先做多项式除法（产生 $\delta$ 项）。Impulse response $g=\L^{-1}[G]$; step response $y=\L^{-1}[G/s]$. If the numerator degree $\ge$ denominator degree, divide first (gives $\delta$ terms).
  2. 分母因式分解，写出部分分式形式：单极点 $\frac{c}{s-p}$；$r$ 重极点 $\frac{c_1}{s-p}+\dots+\frac{c_r}{(s-p)^r}$；共轭对两个复系数（或合成 $\frac{As+B}{(s+\alpha)^2+\omega^2}$）。Factor the denominator and set up the expansion: simple pole $\frac{c}{s-p}$; $r$-fold pole $\frac{c_1}{s-p}+\dots+\frac{c_r}{(s-p)^r}$; a conjugate pair either with two complex coefficients or combined as $\frac{As+B}{(s+\alpha)^2+\omega^2}$.
  3. 系数：$c=\lim(s-p)G$；重极点从最高次往下求导；或者通分比较系数。Coefficients: $c=\lim(s-p)G$; for repeated poles differentiate downward from the highest power; or clear denominators and compare coefficients.
  4. 查表：$\frac{1}{(s+\alpha)^{k}}\to\frac{t^{k-1}}{(k-1)!}e^{-\alpha t}$；共轭对 $ce^{pt}+\bar ce^{\bar pt}=2e^{\alpha t}(x\cos\beta t-y\sin\beta t)$。最后乘 $\sigma(t)$。Table: $\frac{1}{(s+\alpha)^{k}}\to\frac{t^{k-1}}{(k-1)!}e^{-\alpha t}$; conjugate pair $ce^{pt}+\bar ce^{\bar pt}=2e^{\alpha t}(x\cos\beta t-y\sin\beta t)$. Multiply by $\sigma(t)$.
  5. DC gain：先确认极点全在开左半平面，再取 $G(0)$。DC gain: first confirm all poles are in the OLHP, then take $G(0)$.

6 · 传递函数 → 状态空间实现Transfer function → state-space realization

  1. 把 $G$ 写成 $\frac{b_0s^n+\dots+b_n}{a_0s^n+\dots+a_n}$，分子补 0 到 $n$ 次（strictly proper 时 $b_0=0$）。Write $G=\frac{b_0s^n+\dots+b_n}{a_0s^n+\dots+a_n}$, padding the numerator with zeros up to degree $n$ ($b_0=0$ if strictly proper).
  2. 控制器型：$A$ 第一行 $-a_k/a_0$，次对角 1；$b=e_1/a_0$；$c_k=b_k-b_0a_k/a_0$；$d=b_0/a_0$。Controller form: first row of $A$ is $-a_k/a_0$, ones on the subdiagonal; $b=e_1/a_0$; $c_k=b_k-b_0a_k/a_0$; $d=b_0/a_0$.
  3. 观测器型：$A$ 第一列 $-a_k/a_0$，超对角 1；$b_k=b_k-b_0a_k/a_0$；$c=e_1^T/a_0$；$d=b_0/a_0$。Observer form: first column of $A$ is $-a_k/a_0$, ones on the superdiagonal; $b_k=b_k-b_0a_k/a_0$; $c=e_1^T/a_0$; $d=b_0/a_0$.
  4. 自检：用 $c(sI-A)^{-1}b+d$ 算回去。Check: recompute $c(sI-A)^{-1}b+d$.
坑Traps课件控制器型的状态顺序是 $[x^{(n-1)},\dots,x]$（最高阶在上），和很多教材的 $[x,\dot x,\dots]$ 相反，按课件写。bi-proper 时别忘了 $d$。The slides order the states $[x^{(n-1)},\dots,x]$ (highest derivative first), opposite to many textbooks — follow the slides. For bi-proper $G$ don't forget $d$.

7 · BIBO 稳定判断 / 证明BIBO stability: decide / prove

  • 给 $G(s)$：先看是否 proper（不是 ⟹ 不稳定），再看极点（全部 $\operatorname{Re}\lt 0$ ⟹ 稳定）。Given $G(s)$: check properness first (non-proper ⟹ unstable), then poles (all $\operatorname{Re}\lt 0$ ⟹ stable).
  • 给 $g(t)$：算 $\int_0^\infty|g|dt$，有限 ⟺ 稳定。Given $g(t)$: compute $\int_0^\infty|g|dt$; finite ⟺ stable.
  • 按定义证不稳定：给一个有界输入（阶跃 $\sigma$、$\sin\omega_0 t$ 共振），算出无界输出。Disprove by definition: exhibit a bounded input (step $\sigma$, resonant $\sin\omega_0 t$) with an unbounded output.
  • 按定义证稳定：$|y(t)|\le\int_0^t|g(\tau)||u(t-\tau)|d\tau\le M\int_0^\infty|g|$。Prove by definition: $|y(t)|\le\int_0^t|g(\tau)||u(t-\tau)|d\tau\le M\int_0^\infty|g|$.

8 · Routh：多项式稳不稳定Routh: is the polynomial stable?

  1. 首项化正；先看必要条件：有系数 $\le0$ 或缺项 ⟹ 直接“不稳定”。Make $a_0>0$; check the necessary condition: any coefficient $\le0$ or missing ⟹ unstable immediately.
  2. 前两行：偶数位、奇数位系数。之后每个元素 = $\dfrac{(\text{上一行首})\times(\text{上上行右邻})-(\text{上上行首})\times(\text{上一行右邻})}{\text{上一行首}}$。First two rows: even- and odd-indexed coefficients. Each new entry $=\dfrac{(\text{first of row above})\times(\text{right neighbour two rows up})-(\text{first two rows up})\times(\text{right neighbour of row above})}{\text{first of row above}}$.
  3. 第一列全 $>0$ ⟹ 稳定；出现负数或 0 ⟹ 不稳定（0 时停止）。First column all $>0$ ⟹ stable; a negative or zero ⟹ unstable (stop at a zero).
提速Speed-ups可以把一整行同乘一个正数（不改变符号）；三阶 $s^3+a_1s^2+a_2s+a_3$ 稳定 ⟺ $a_i>0$ 且 $a_1a_2>a_3$；二阶 ⟺ 系数全正。You may scale a whole row by a positive number; cubic $s^3+a_1s^2+a_2s+a_3$ is stable ⟺ all $a_i>0$ and $a_1a_2>a_3$; quadratic ⟺ all coefficients positive.

9 · 求使闭环稳定的 $K$ 范围Range of $K$ for closed-loop stability

  1. 写特征多项式：单位负反馈 $L=\frac{N}{D}$ ⟹ $D+KN$；一般 $P=\frac ba, C=\frac qp$ ⟹ $ap+bq$。确认适定（$P$ strictly proper 就自动满足）。Characteristic polynomial: unity feedback $L=\frac{N}{D}$ ⟹ $D+KN$; in general $P=\frac ba, C=\frac qp$ ⟹ $ap+bq$. Confirm well-posedness (automatic if $P$ is strictly proper).
  2. 按 $s$ 降幂整理，系数是 $K$ 的表达式。Collect in descending powers of $s$; coefficients are expressions in $K$.
  3. Routh 表（含 $K$），第一列每一项 $>0$ ⟹ 一组不等式。分式项要注意分母符号（通常分母本身就是前面要求 $>0$ 的项）。Routh table with $K$; require every first-column entry $>0$ ⟹ a set of inequalities. For fractions mind the denominator's sign (usually it is an earlier entry already required $>0$).
  4. 解每个不等式，取交集，写成区间；二次不等式求根后判断开口。Solve each inequality and take the intersection; for quadratics find the roots and check the sign pattern.
  5. 代一个区间内的 $K$ 和一个区间外的 $K$ 验证。Verify with one $K$ inside and one outside the interval.

11 · 参数在区间内：KharitonovParameters in intervals: Kharitonov

  1. 写出闭环特征多项式，确认每个系数独立在一个区间里变化（若两个系数依赖同一个参数，就不是区间多项式，不能直接用）。Write the closed-loop characteristic polynomial and check that each coefficient varies independently in an interval (if two coefficients share a parameter it is not an interval polynomial).
  2. 从 $a_0$ 开始按 LLUU / LUUL / ULLU / UULL 写出 4 个多项式。Starting at $a_0$, write the four polynomials with LLUU / LUUL / ULLU / UULL.
  3. 4 个都 Routh 稳定 ⟹ 全部稳定；有一个不稳定 ⟹ 不是对所有参数都稳定（那个多项式就是反例）。All four Routh-stable ⟹ all members stable; one unstable ⟹ not robustly stable (that polynomial is a counterexample).

12 · 闭环内稳定判断Is the closed loop internally stable?

  1. 把 $P=\frac ba$、$C=\frac qp$ 各自化成互质形式。Reduce $P=\frac ba$ and $C=\frac qp$ to coprime form.
  2. 适定：$1+P(\infty)C(\infty)\ne0$（任一 strictly proper 就成立）。不满足 ⟹ 不内稳定。Well-posed: $1+P(\infty)C(\infty)\ne0$ (automatic if either is strictly proper). Otherwise ⟹ not internally stable.
  3. 算 $c=ap+bq$，Routh / 求根：稳定 ⟺ 内稳定。Compute $c=ap+bq$; Routh / roots: stable ⟺ internally stable.
  4. （另一条路）检查 $PC$ 中是否有右半平面（含虚轴）的零极点对消，有 ⟹ 不内稳定；没有 ⟹ 只需检查一个 gang-of-four 传递函数。(Alternative) look for pole/zero cancellations in the closed RHP within $PC$: any ⟹ not internally stable; none ⟹ checking one gang-of-four entry suffices.
坑Traps只看 $\frac{PC}{1+PC}$（对消后看起来稳定）；忘了 non-proper 闭环；把“控制器不稳定”当成“闭环不稳定”。Checking only $\frac{PC}{1+PC}$ (looks stable after cancellation); missing a non-proper closed loop; confusing “unstable controller” with “unstable closed loop”.

13 · 极点配置（Diophantine）Pole placement (Diophantine)

  1. $P=\frac{b}{a}$，$n=\deg a$。定控制器阶数：proper 取 $m=n-1$，strictly proper 取 $m=n$（题目指定就照题目）。$P=\frac{b}{a}$, $n=\deg a$. Controller order: proper $m=n-1$, strictly proper $m=n$ (unless the problem specifies).
  2. 期望多项式 $c(s)=\prod(s-\lambda_i)$，必须恰好 $n+m$ 个极点；共轭对 $-\alpha\pm j\beta$ 对应 $s^2+2\alpha s+\alpha^2+\beta^2$。Desired polynomial $c(s)=\prod(s-\lambda_i)$ with exactly $n+m$ poles; a pair $-\alpha\pm j\beta$ gives $s^2+2\alpha s+\alpha^2+\beta^2$.
  3. 设 $C=\frac{q_0s^m+\dots+q_m}{p_0s^m+\dots+p_m}$（strictly proper 时 $q_0=0$），展开 $a p+b q$ 与 $c$ 比较系数（或写 Sylvester 矩阵方程 $S(a,b,m+1)[p;q]=c$）。Let $C=\frac{q_0s^m+\dots+q_m}{p_0s^m+\dots+p_m}$ ($q_0=0$ if strictly proper); expand $ap+bq$ and match coefficients with $c$ (or write $S(a,b,m+1)[p;q]=c$).
  4. 从最高次 / 最低次开始逐个解（通常 $p_0=c_0/a_0$ 和最后一个方程最简单）。Solve from the top and bottom equations first ($p_0=c_0/a_0$ and the constant-term equation are usually trivial).
  5. 写出 $C(s)$，验证 $ap+bq=c$；如问 “stable controller?” 看 $p(s)$ 的根。Write $C(s)$ and verify $ap+bq=c$; for “stable controller?” check the roots of $p(s)$.
